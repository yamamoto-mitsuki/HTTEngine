# 20. UI

画面に重ねる UI（図形・線・切り抜き・模様・文字・ワールドの物に重ねる・画面の比率・ポーズ画面などの画面・状態で動かす）。透明度をまとめて変える Alpha Group は [14章の Trigger Activator・Alpha Group](14-MathCollision.md#範囲に入ったら出すtrigger-activatoralpha-group)。

## 画像を使わない UI の図形（Vector Shape）

Hierarchy の ＋ → Vector Shape（Add Component → UI → Vector Shape）。四角形・角丸四角形・円・楕円・リング・平行四辺形を、シェーダーで描く（作りは `../Tasks/VectorShape.md`）。置き方は Image と同じ（Translation の x・y がピクセル・Anchor・Pivot・Order・Blend。Image・Text と Order で重なり、Alpha Group も効く）。

- **Style**：`Fill`（塗り）・`FillAndStroke`（塗りと縁取り）・`Stroke`（線だけ）。縁取りの太さと角の丸みは Size を変えても変わらない。
- **Gradient**：`Linear`・`Radial`。Color から Gradient Color へ。Range で色が変わる範囲を決める。
- **Gauge**：`Linear`・`Radial`。Amount（0〜1）で見せる割合を決める。塗りと縁取りを一緒に切るので、背景の枠は別の Vector Shape を後ろに置く。
- **Transform の Scale**：Size は x・y それぞれ、丸み・縁取り・リングの太さは x・y の小さい方の倍率が掛かる。
- 値は Script から毎フレーム書いてよい（バッファを作り直さない）：

```cpp
if (VectorShapeComponent* shape = GetComponent<VectorShapeComponent>()) {
	shape->gaugeAmount = value / maxValue;
}
```

- ボタンは `VectorShapeSystem::IsMouseOver(entity)`（Size の四角で調べる）。

## 点をつないだ UI の線・形（Polyline）

Hierarchy の ＋ → Polyline（Add Component → UI → Polyline）。点（最大 32）をつないだ線で、点ごとの Radius で角を円弧に曲げる（作りは `../Tasks/Polyline.md`）。置き方は Image と同じ（点は Entity の位置を原点にしたピクセルで Y は上が＋・Anchor・Order・Blend。Image・Vector Shape・Text と Order で重なり、Alpha Group も効く）。

- **Closed** で閉じた形。**Style** が `Fill`・`FillAndStroke` なら中を塗る（閉じた形だけ）。
- **Stroke Width**・**Stroke Color**・**Cap**（`Butt`・`Round`・`Square`。開いた線の端）。半径 0 の角は、外が丸く内がとがる。半径はとなりの辺に収まるように縮む。
- **Edit Points** で、Scene ビューの点を動かす（■ をドラッグ・辺の真ん中の ＋ で足す・選んで Delete で消す・Esc で終わる）。
- Timeline の Value トラックで点を動かせる（Property は `point0`・`point1`…、半径は `radius0`…）。
- 点・半径・太さ・Scale を変えた時だけ、形（メッシュ）を作り直す。位置・回転・色・透明度は変えても作り直さない：

```cpp
if (PolylineComponent* polyline = GetComponent<PolylineComponent>()) {
	polyline->points[2].y = std::sin(time) * 40.0f;
}
```

## UI を図形の形で切り抜く（UI Mask）

Vector Shape か Polyline のある Entity に Add Component → UI → **UI Mask**。子（孫も）の UI を、その形で切り抜く（作りは `../Tasks/UIMask.md`）。

- 入れ子にすると、外と内のマスクの重なった所だけになる（8 段まで）。
- マスクの子は、マスクの図形の Order の所にまとめて描く（子どうしは子の Order）。
- 切り口はなめらかにならない。図形の縁取り（Stroke）は子の上に描くので、切り口を隠せる。
- **Show Graphic** を外すと、図形は見えずに切り抜くだけ。

## 模様を並べる（Image の Tiled）

Image の **Tiled** をオンにすると、画像全体を **Tile Size**（ピクセル。0 は画像の大きさ）ごとに並べる。Size を変えても模様は伸びず、並ぶ数が変わる。**Tile Offset**（1 で1枚分）を Timeline で動かすと、模様が流れる。

## ゲームの画面の比率と黒帯（GameScreen）

`main.cpp` の `WindowConfig` で決める。書かなければ 1280×720（作りは `../Tasks/GameScreen.md`）。

```cpp
config.width = 540;       // ウィンドウの大きさ
config.height = 960;
config.gameWidth = 720;   // ゲームの画面（縦横比と UI のピクセルの基準）
config.gameHeight = 1280;
```

- UI の位置・大きさは `gameWidth`×`gameHeight` のピクセルで置く。カメラの縦横比もこの値。
- ウィンドウの比率が違うと、製品版は上下か左右に黒帯が出る（絵は伸びない）。エディタの Game・Scene ビューも比率を保つ。
- 帯の色は `RenderWindow::kBarColor`。クリアの色 `kClearColor` とは別の値。
- `InputManager::GetMousePositionInGame` は黒帯の内側を画面として数える。黒帯の上では `IsMouseInGame` が false。
- 起動の後は変えられない。コードから読むときは `GameScreen::GetWidth()`・`GetHeight()`・`GetAspectRatio()`。

## 画面に文字を出す（Text）

Hierarchy の ＋ → Text（Add Component → UI → Text）。置き方は Image と同じ（Translation の x・y がピクセル・Anchor・Pivot・Order）。Script から書き換える：

```cpp
if (TextComponent* text = scoreText_.GetComponent<TextComponent>()) {
	text->text = std::format("SCORE {:06}", score_); // text は FixedString<256>（"..."・std::string を入れられる。読むときは text->text.View()）
}
```

- フォントは Inspector で選ぶ（見本つき。`resources/` の下と Windows のフォント）。(none) はメイリオ。縁取り（Outline Width）・影（Shadow）。
- 大きさが要るときは `TextRenderSystem::CalcTextSize(entity)`。

## UI をワールドの物に重ねる（UI World Follow）

UI（Image・Text・Vector Shape・Polyline）の一番上の Entity に Add Component → UI → **UI World Follow**。敵に重ねるマーク・名札・当たった所に出す数字・画面の端の「あっちにいる」矢印に使う（作りは `../Tasks/UIWorldFollow.md`）。

- **Target**（`EntityRef`）の位置＋ **World Offset**（ワールドの向き・m）を、ゲームのカメラで画面に写した所に置く。Target が none なら World Offset をワールドの点として使う。
- Transform の Translation は書き換えない。x・y は「写した点からのずれ（ピクセル・上が＋）」になるので、Tween・Timeline で Translation を動かすと、重ねた所からポンと浮く動きが書ける。子は置いた後の位置について来る。
- この Entity と子の UI の **Anchor は Center にする**（ほかはずれる。Inspector に注意が出る）。
- **Offscreen**：点が画面の外・カメラの後ろのとき `Keep`（そのまま）・`Hide`（隠す。既定）・`ClampToEdge`（画面の端から **Edge Margin** ピクセル内側に寄せる）。
- 停止中も重ねる（エディタで重なった見た目を見ながら置ける）。カメラが動いた後に置くので、カメラを追いかけても揺れない。
- Script から `target`・`worldOffset` を書くと、次の置き直しから変わる。結果は毎フレーム書かれる：

```cpp
if (UIWorldFollowComponent* follow = GetComponent<UIWorldFollowComponent>()) {
	follow->target = EntityManager::RefOf(enemy.handle); // enemy は重ねる相手の GameObject
	// follow->isOnScreen（画面の中に写っている）・isClamped（端に寄せた）・isHidden（隠している）
	// follow->edgeAngle（画面の真ん中から点への向き。度。右が 0、上が 90。端の矢印を回すのに使う）
}
```

## 画面（UI Screen）：ポーズ画面・クリア画面

`resources/ui/<名前>.uiscreen`（中身は Prefab と同じ形。全部のシーンで使える）。

1. **作る**：Project ウィンドウの右クリック → **Create → UI Screen**。名前を打つ。
2. **直す**：ダブルクリック（Inspector の **Edit UI Screen**）で編集モード（停止中だけ）。Scene ビューに水色の枠（ゲームの画面＝`gameWidth`×`gameHeight` の大きさ）、Hierarchy は画面の中身だけ。後ろのシーンは見えるが選べない。**Done** で保存して閉じる・**Cancel** で保存せずに閉じる。Save（Ctrl+S）はシーンと画面の両方。Play を押す・シーンを開くと、先に Done と同じことをする。
3. **出し方・消し方**：一番上の Entity の **UI Screen** Component（Pause Game・Time Mode・Show／Hide）。Show・Hide に **Timeline** を選ぶと、一番上の Entity を再生する Entity にしてそれを再生する（Timeline ウィンドウの `UI Screen / Show`・`Hide` の欄で作ってプレビューできる。[Tasks/UIAnimation.md](../Tasks/UIAnimation.md)）。選ばなければ **Motion**（None / Fade / Slide / Scale、Side・Distance・From Scale・With Fade・Duration・Ease・Stagger）で、一番上の**直下の子**が1つずつ動く（Hierarchy の上から順に Stagger 秒ずつ遅れる）。子に **UI Screen Element** を付けると、その子だけ Motion を変えられる（Delay で遅れも足せる）。出している途中に閉じても、その時の形から消える（Timeline は Hide の Tween の From を Current にする）。
4. **使う**：
```cpp
UIScreen::Open("Pause");   // 出す（停止中・もう出ている・消している途中・ファイルが無いときは false。見え始めるのは次のフレーム）
UIScreen::Close("Pause");  // 消す（消す動きが終わったら Entity を消す。消し始めたらすぐゲームが動く）
UIScreen::IsOpen("Pause"); // 出ているか（出している途中は true・消している途中は false）
UIScreen::GetRoot("Pause");// 一番上の Entity（TimelineSystem::SetParameter で出し方の値を変える）
UIScreen::CloseContaining(entity); // entity が入っている画面を消す
```
- Pause Game の画面を出している間は `Time::SetGamePaused(true)`。**ポーズ中も、開いている画面の中の Script は呼ばれる**（項目を選ぶ Script を画面の中に置く）。
- シーンが変わると一緒に消える（開いたまま次のシーンへ持っていくのは、まだ無い）。

## 要素の状態で動かす（UI State）

要素に **UI State**（Add Component → UI）を付けると、状態が変わったときにその状態の Timeline を再生する（Timeline の対象を空にすると、その要素を動かす）。マウスの当たりは同じ Entity の Vector Shape か Image。

- 状態：Disabled（Interactable を外す）＞ Pressed ＞ Hover ＞ Selected（`UIStateSystem::SetSelected`）＞ Normal。Timeline を選んでいない状態は Normal を再生する。
- Show・Hide：`UIStateSystem::SetVisible(entity, false)` で Hide を再生し、消えている間はマウスに反応しない。
- Click：Open Screen・Close Screen・Close Own Screen・Switch Screen をコード無しで。Script からは `UIStateSystem::IsClicked(entity)`（次のフレームに1回 true）。
- ポーズ中は、開いている画面の中の要素だけが反応する。Time Mode が Real なら、ポーズ中も動く。
- 同じ項目を UI Screen の Show・Hide と UI State の両方で動かすと、UI Screen が勝つ（後の層。終わった後は最後に書いた値が残る）。出し入れは位置と透明度、状態は大きさと色、のように分けるとよい。
